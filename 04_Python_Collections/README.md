# 🔄 C++ STL vs Python

| C++ STL | Python Equivalent | Primary Use |
|----------|-------------------|-------------|
| `vector` | `list` | Dynamic Array |
| `pair` | `tuple` | Store Fixed Values |
| `stack` | `list` | LIFO Operations |
| `queue` | `collections.deque` | FIFO Operations |
| `priority_queue` | `heapq` | Priority Queue |
| `set` | `set` | Unique Elements |
| `unordered_set` | `set` | Fast Lookup |
| `map` | `dict` | Key-Value Storage |
| `unordered_map` | `dict` | Fast Key Lookup |
