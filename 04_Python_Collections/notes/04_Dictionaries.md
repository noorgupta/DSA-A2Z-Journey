# Dictionary

## 📖 What is a Dictionary?

A dictionary is a mutable collection that stores data in **key-value pairs**.

Each key is unique and is used to access its corresponding value.

Example:

```python
student = {
    "name": "Noor",
    "age": 20,
    "course": "BCA"
}
```

---

## 🤔 Why Am I Learning Dictionaries?

Dictionaries help me:

- Store data as key-value pairs.
- Find values quickly using keys.
- Count frequencies.
- Solve hashing-based DSA problems.
- Improve time complexity in many problems.

---

## 📌 Characteristics

- Stores data as key-value pairs.
- Mutable.
- Keys must be unique.
- Keys must be immutable.
- Fast lookup using keys.

---

## Example

```python
student = {
    "name": "Noor",
    "age": 20
}

print(student["name"])
```

Output

```
Noor
```
