# List

## 📖 What is a List?

A list is an ordered, mutable collection in Python that can store multiple values under a single variable.

It is the most commonly used collection in Python and serves as the equivalent of a **dynamic array** in many programming languages.

Example:

```python
numbers = [10, 20, 30, 40]
```

---

## 🤔 Why Am I Learning Lists?

Lists are one of the most frequently used data structures in DSA.

Most beginner and intermediate problems involving arrays are solved using Python lists.

Understanding lists thoroughly will make learning Arrays, Sorting, Searching, Sliding Window, Two Pointers, and many other DSA topics much easier.

---

## 📌 Characteristics

- Ordered
- Mutable (modifiable)
- Allows duplicate values
- Supports indexing
- Supports slicing
- Can store different data types

---

## Example

```python
student = ["Noor", 20, 8.5, True]
```

Although Python allows mixed data types, in DSA we generally store the same type of data together.

Example:

```python
marks = [90, 85, 70, 95]
```

---

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Access | O(1) |
| Update | O(1) |
| Search | O(n) |
| Insert (End) | O(1) Average |
| Insert (Middle) | O(n) |
| Delete (End) | O(1) |
| Delete (Middle) | O(n) |
