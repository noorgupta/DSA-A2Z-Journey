# Set

## 📖 What is a Set?

A set is an **unordered**, **mutable** collection that stores **only unique elements**.

If duplicate values are added, the set automatically removes them.

Example:

```python
numbers = {10, 20, 30}
```

---

## 🤔 Why Am I Learning Sets?

Sets are extremely useful when I need to:

- Remove duplicate elements.
- Check if an element exists quickly.
- Perform mathematical set operations.
- Solve hashing-related DSA problems.

---

## 📌 Characteristics

- Unordered
- Mutable
- Does not allow duplicate values
- Does not support indexing
- Fast lookup

---

## Example

```python
numbers = {10, 20, 30, 20}

print(numbers)
```

Output

```
{10, 20, 30}
```

Notice that the duplicate `20` is automatically removed.
