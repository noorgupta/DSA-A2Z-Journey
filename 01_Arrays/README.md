## 📖 About

This module introduces the fundamental concepts of **Arrays** and **Strings** required before solving Data Structures and Algorithms problems.

The focus of this section is to build a strong conceptual understanding of:

- How arrays work
- How strings are represented
- Basic array operations
- Traversal techniques
- Python list methods
- Searching fundamentals
- Time and Space Complexity

These concepts form the foundation for advanced topics such as Arrays, Hashing, Sorting, Binary Search, Dynamic Programming, and many more.

> **Note:** Python does not have a built-in fixed-size array like C/C++. Throughout this repository, Python **lists** are used to implement array concepts.

# 🛠 Python List Methods

| Method | Purpose | Time Complexity |
|---------|---------|-----------------|
| `append()` | Add one element at the end | O(1) Average |
| `extend()` | Add multiple elements | O(k) |
| `insert()` | Insert an element at a specific index | O(n) |
| `pop()` | Remove an element using its index | O(1) / O(n) |
| `remove()` | Remove the first occurrence of a value | O(n) |
| `clear()` | Remove all elements | O(n) |
| `index()` | Find the first occurrence of a value | O(n) |
| `count()` | Count occurrences of a value | O(n) |
| `sort()` | Sort the list | O(n log n) |
| `reverse()` | Reverse the list | O(n) |
| `copy()` | Create a shallow copy | O(n) |

# 💡 Key Takeaways

- Arrays store multiple related values under a single variable.
- Python lists are implemented as dynamic arrays.
- Arrays use **0-based indexing**.
- Traversal is the basis of almost every array algorithm.
- Choosing the correct list method improves readability and efficiency.
- Time and Space Complexity help evaluate algorithm performance.
